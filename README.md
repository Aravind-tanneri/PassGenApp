# 🔐 PassGen - Professional Password Generator

PassGen is a sleek, modern, and highly secure mobile application built with **React Native** and **NativeWind (Tailwind CSS)**. It allows users to generate strong, randomized passwords based on custom security requirements.

## 🚀 Features

- **Customizable Security**: Toggle between Lowercase, Uppercase, Numbers, and Symbols.
- **Dynamic Length**: Smooth slider to adjust password length (4-16 characters).
- **Strength Indicator**: Real-time visual feedback (Weak, Good, Strong) based on password complexity.
- **Smart Guard**: Prevents unselecting all character types to ensure valid generation.
- **One-Tap Copy**: Powered by `expo-clipboard` with instant visual toast feedback.
- **Dark Mode**: Seamless transition between Light and Dark themes.
- **History Tracking**: Keeps track of your last 5 generated passwords.

## 🛠️ Tech Stack

- **Framework**: React Native (Expo)
- **Styling**: NativeWind (Tailwind CSS)
- **Form Handling**: Formik
- **Validation**: Yup
- **Icons/UI**: Bouncy Checkbox & Community Slider
- **Notifications**: React-Native-Toast-Message
